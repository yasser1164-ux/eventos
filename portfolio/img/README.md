# Portfolio images

Drop image files here and the site picks them up.

## Portrait

Save your photo as **`yasir.jpg`** in this folder.

- Portrait orientation, roughly 4:5 (e.g. 640 × 800 px)
- Face centred and reasonably tight — the frame crops with `object-fit: cover`
- Keep it under ~300 KB so the page stays fast

Until that file exists, the About section shows a "YA" monogram in the frame
instead, so the page never renders a broken image.

The source photo is in Dropbox at `/Personal/My_photo.jpg`.
