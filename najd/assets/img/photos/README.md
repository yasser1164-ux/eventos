# صور الموقع / Site photographs

كل الصور في الموقع مرسومة برمجيًا (رسوم توضيحية)، ويمكن استبدال أي منها بصورة
حقيقية بلا أي تعديل في الكود:

1. ضع الصورة في هذا المجلد (`najd/assets/img/photos/`).
   المقاس المناسب: عرض ١٦٠٠ بكسل تقريبًا، بصيغة JPG، وأقل من ٤٠٠ كيلوبايت.
2. افتح `manifest.json` وأضف سطرًا يربط اسم الموضع باسم الملف:

```json
{
  "warehouse": "warehouse.jpg",
  "site": "our-site-2026.jpg",
  "P-1001": "rebar.jpg"
}
```

3. احفظ وارفع التغيير. تظهر الصورة مكان الرسم مباشرة.

## المواضع المتاحة

| الموضع | يظهر في |
|---|---|
| `site` | قسم مواد البناء · قصة الشركة · مشروع مجمع سكني |
| `warehouse` | القسم التعريفي بالرئيسية · الخدمات اللوجستية · صفحة أعمالنا |
| `logistics` | قسم «كيف نعمل» بالرئيسية · قطاع التجزئة |
| `port` | قسم الاستيراد والتخليص · مشروع ميناء جدة |
| `plant` | الإمدادات الصناعية · قطاع النفط والغاز · مشروع مصنع الدمام |
| `power` | المعدات الكهربائية · قطاع المرافق · مشروع اللوحات والكابلات |
| `safety` | قسم السلامة ومعدات الوقاية |
| `office` | المسار الزمني في «من نحن» · القطاع الحكومي |
| `trade` | متاح للاستخدام العام |
| `P-1001` … `P-5002` | صور المنتجات في الكتالوج (رقم الصنف كما يظهر على البطاقة) |
| `PR-01` … `PR-04` | صور صفحة «أعمالنا» |

ملاحظة: إن لم يُذكر اسم في `manifest.json` يبقى الرسم التوضيحي كما هو — لا تنكسر
الصفحة أبدًا. ولو أردت أن يبحث الموقع عن الصور تلقائيًا دون تحديث القائمة، اضبط
`photos: { autodetect: true }` في `assets/js/config.js`.
