# نجد الشرق الأوسط للتجارة — موقع الشركة
# Najd Middle East Trading — company website

موقع تعريفي كامل لشركة توريد وتجارة، ثنائي اللغة (عربي/إنجليزي)، بصفحات
حقيقية ونماذج تعمل فعليًا. مبني بـ HTML/CSS/JS فقط — بلا خطوات بناء وبلا
اعتماديات — فيمكن نشره على GitHub Pages أو أي استضافة ملفات ثابتة.

A complete bilingual (Arabic-first, English) marketing site for a trading and
supply company: real pages, working forms, no build step, no dependencies.

**الرابط الحالي / Live:** https://yasser1164-ux.github.io/eventos/najd/
(يُنشر تلقائيًا عند الدمج في `main` — انظر `.github/workflows/pages.yml`)

## ما الذي في الموقع / What's inside

| الصفحة | الملف | المحتوى |
|---|---|---|
| الرئيسية | `index.html` | واجهة + نموذج طلب سريع + إحصاءات + الأقسام + القطاعات + خطوات العمل + منتجات مختارة + آراء + أسئلة |
| من نحن | `about.html` | القصة، الرؤية والرسالة والقيم، المسار الزمني، هيكل الفريق، الالتزام النظامي |
| خدماتنا | `services.html` | تفصيل الأقسام الستة + خدمات مساندة + الأسئلة الشائعة |
| المنتجات | `products.html` | كتالوج ببحث وتصفية وترتيب، وإضافة إلى طلب التسعير |
| أعمالنا | `projects.html` | نماذج عمليات توريد بمؤشرات |
| اطلب عرض سعر | `quote.html` | نموذج RFQ كامل + قائمة الأصناف المختارة من الكتالوج |
| تواصل معنا | `contact.html` | نموذج مراسلة + بيانات التواصل + خريطة |
| الوظائف | `careers.html` | الشواغر + نموذج تقديم |
| قانوني | `privacy.html` · `terms.html` | سياسة الخصوصية والشروط (صيغ أولية تحتاج مراجعة قانونية) |
| خطأ | `404.html` | صفحة غير موجودة |

مزايا عامة: تبديل عربي/إنجليزي كامل مع تغيير اتجاه الصفحة، وضع ليلي/نهاري
يتبع إعداد الجهاز، تصميم متجاوب حتى ٣٢٠ بكسل، بيانات Schema.org، خريطة موقع،
صور Open Graph، وأيقونة موقع.

## البنية / Structure

```
najd/
├── *.html                  الصفحات المنشورة (مولَّدة — لا تُحرَّر مباشرة)
├── assets/
│   ├── css/styles.css      نظام التصميم كاملًا (ألوان، مكونات، استجابة)
│   └── js/
│       ├── config.js       ⚙️  بيانات الشركة — عدّل هذا الملف أولًا
│       ├── lang-en.js      كل النصوص الإنجليزية (العربية داخل الـ HTML)
│       ├── i18n.js         محرك اللغة والاتجاه
│       ├── data.js         📦 الأقسام والقطاعات والمنتجات والأعمال والوظائف والأسئلة
│       ├── media.js        يرسم كل الصور كـ SVG وقت التشغيل (لا صور خارجية)
│       ├── cart.js         قائمة الأصناف المختارة (تُحفظ في المتصفح)
│       ├── ui.js           الهيدر، القائمة، المظهر، الحركات، العارضات
│       ├── forms.js        التحقق من النماذج وإرسالها
│       ├── catalog.js      بحث وتصفية الكتالوج
│       └── pages.js        ربط النماذج وقائمة طلب التسعير
├── tools/                  مولّد الصفحات (يوحّد الهيدر والفوتر)
│   ├── shell.html          الإطار المشترك لكل صفحة
│   ├── pages/*.html        محتوى كل صفحة
│   └── build.js            node najd/tools/build.js
├── sitemap.xml · robots.txt · site.webmanifest
```

> **مهم:** ملفات `najd/*.html` مولَّدة. لتعديل الهيدر أو الفوتر عدّل
> `tools/shell.html`، ولتعديل محتوى صفحة عدّل `tools/pages/<الصفحة>.html`،
> ثم شغّل `node najd/tools/build.js`. (لا يحتاج الموقع إلى Node للعمل —
> فقط لإعادة توليد الصفحات.)

## خطوات ما قبل الإطلاق / Before going live

1. **بيانات الشركة** — `assets/js/config.js`: الاسم، الهاتف، الواتساب، البريد،
   العنوان، أوقات العمل، السجل التجاري والرقم الضريبي، وروابط التواصل.
   القيم الحالية **أرقام توضيحية** ويجب استبدالها.
2. **نفس البيانات في البيانات المنظمة** — `tools/shell.html` (كتلة
   `application/ld+json`) ثم إعادة البناء.
3. **الكتالوج والمحتوى** — `assets/js/data.js` (منتجات، أقسام، أعمال، وظائف، أسئلة).
   كل عنصر يحمل نصًا عربيًا وإنجليزيًا.
4. **الصفحات القانونية** — راجع `privacy.html` و`terms.html` قانونيًا.
5. **الأرقام التوضيحية** — مؤشرات صفحة «أعمالنا» وآراء العملاء نماذج للعرض؛
   استبدلها ببيانات حقيقية أو احذفها من `data.js`.
6. **النطاق** — عند شراء نطاق خاص، غيّر `BASE` في `tools/build.js` وأعد البناء،
   وحدّث `sitemap.xml` و`robots.txt`.

## استقبال الطلبات / Where form submissions go

الوضع الافتراضي `mode: "local"` في `config.js`: كل طلب يُحفظ في متصفح الزائر
ويُعطى **رقم مرجع**، ويظهر زر يفتح رسالة بريد جاهزة إليكم. يعمل اليوم بلا أي
حساب أو خادم — لكن لا يصلك الطلب تلقائيًا. للاستقبال التلقائي اختر أحد الوضعين:

**أ) Formspree (الأسهل، دقيقتان)**
1. أنشئ نموذجًا مجانيًا على formspree.io واحصل على رابط مثل
   `https://formspree.io/f/xxxxxxxx`.
2. في `config.js`: `mode: "formspree"` و`formspreeEndpoint: "<الرابط>"`.

**ب) Supabase (قاعدة بيانات كاملة)**
1. أنشئ مشروعًا على supabase.com ونفّذ في SQL Editor:

```sql
create table inquiries (
  id          bigint generated always as identity primary key,
  created_at  timestamptz default now(),
  reference   text, kind text, name text, email text,
  phone       text, company text, payload jsonb
);
alter table inquiries enable row level security;
create policy "anon can insert" on inquiries for insert to anon with check (true);
```

2. في `config.js`: `mode: "supabase"` مع `supabaseUrl` و`supabaseAnonKey`.
   مفتاح `anon` آمن للنشر: السياسة أعلاه تسمح بالإضافة فقط ولا تسمح بالقراءة.

جميع الطلبات تُختم برقم مرجع بصيغة `NJD-YYMMDD-XXXX`، وتُحفظ نسخة محلية في
`localStorage` تحت `najd.submissions` في كل الأحوال.

## التشغيل محليًا / Run locally

```bash
npx http-server -p 8080 -c-1     # ثم افتح http://localhost:8080/najd/
node najd/tools/build.js         # بعد أي تعديل داخل tools/
```

## ملاحظات تقنية / Technical notes

- **لا صور خارجية:** كل الرسوم تُولَّد كـ SVG في `media.js` من معرّف كل عنصر،
  فالمستودع نصي بالكامل ولا توجد مشاكل تراخيص. لاستبدالها بصور حقيقية،
  ضع الصور في `assets/img/` واستبدل استدعاء `MEDIA.art(...)`.
- **الترجمة:** العربية هي المصدر داخل الـ HTML؛ `i18n.js` يلتقطها عند التحميل
  ويستبدلها بنصوص `lang-en.js` عند اختيار الإنجليزية. مفتاح ناقص = يبقى النص
  العربي، فلا ينكسر شيء أبدًا. يمكن فتح الموقع بلغة محددة عبر `?lang=en`.
- **بلا جافاسكربت:** النصوص الأساسية وبيانات التواصل تظهر كما هي؛ القوائم
  المولَّدة (الكتالوج مثلًا) هي ما يحتاج تفعيل الجافاسكربت.
- **الوصولية:** روابط تخطٍّ، تركيز ظاهر، تسميات للحقول، ودعم
  `prefers-reduced-motion`.
